# Jatin Rawat Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. Open `index.html` locally or deploy the folder as a static site (for example, on Netlify). The resume download is included at `assets/Resume.pdf`.

The contact form posts to FormSubmit for `jatinsinghrawat759@gmail.com`. FormSubmit may send a one-time activation email to that inbox on the first submission; activate the form there before expecting messages to arrive. The site uses stock photography from Unsplash and technology icons from Devicon CDN.
